DATABASE
--------
SQLite file:  invisibleink.db  (in the same folder as InvisibleInk.exe)
No username or password. To look inside it, open the file with
"DB Browser for SQLite" (free: https://sqlitebrowser.org).

Tables: StaffInformation, PiercingData, InformationCustomer, Bookings
